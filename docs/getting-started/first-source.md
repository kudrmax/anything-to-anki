# Your first source

This walkthrough takes one text from adding to Anki. It takes about ten minutes. You need the app running (`make up`) and, for the last step, Anki.

## 1. Set your level

Open **Settings → Vocabulary**, choose your **Target CEFR level**, and press **Save settings**. The app suggests words above this level.

## 2. Add a text

1. Find an English text you'd like to read: a news article, a story, a chapter of a book. Copy its text.
2. On the **Sources** screen, paste it into the **Add** box.
3. Type a **Title**, for example `My first article`.
4. Press **Add source**.
5. The app asks **Is it a text or a song?** Choose **Text** and press **Confirm**.

The source appears in the list with **Not processed yet**.

## 3. Process it

Press **Process** on the source. An overlay shows the progress. For an article this takes a few seconds.

When it is done, the source shows how many phrases it has, and a **Review** button.

## 4. Generate meanings

1. Press **Review**. The Review screen opens on the first card.
2. Open the **✨** menu in the header.
3. Choose **Phrases → Ready: generate missing**. AI rewrites long, hard sentences into short, simple ones.
4. Choose **Meanings → Ready: generate missing**.
5. Choose **Speech → Ready: generate missing** to have the phrases read aloud.

Jobs run in the order you start them. Start **Phrases** before **Meanings**: a phrase that gets simplified later loses its meaning and needs a new one.

Meanings arrive within a minute or two, card by card. You can start reviewing right away.

## 5. Review

For each card, read the phrase and its meaning, then decide:

- **Learn** (`L` or `Space`): you want to learn this word.
- **Know** (`K`): you already know it; it won't be suggested again.
- **Skip** (`S`): not this phrase, maybe another one.

Start with the **Ready** section: phrases where the target is the only new word. See [Reviewing cards](../guide/review.md) for everything else a card can do.

## 6. Send to Anki

1. Start Anki.
2. Press **Export N** in the Review header, or open **Export** in the top bar.
3. Press **Add to Anki · N cards**.

The cards are in Anki's `Default` deck, with the tag `anything-to-anki`.
