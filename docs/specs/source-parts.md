# Части источника, порции и обновление без потерь

Продуктовые решения согласованы с Максом 14.10.2026, история обсуждения — в документе «Большие источники — проблема». После продуктового ревью спеки фильтры «Где» / «В работе» заменены **порциями** (решение Макса 14.10.2026).

## Цель

Большой источник (книга, сериал, огромная статья) не генерируется целиком и не замораживается на момент загрузки.

- Человек явно берёт **порцию** слов: откуда, сколько и в каком порядке — видно в момент взятия, ничего не зависит от скрытого состояния экрана.
- Карточки, во что человек ещё ничего не вложил, всегда можно пересобрать по текущей логике и знаниям, не трогая остальное.
- Фраза для слова берётся из выбранного куска: готовишься к главе 3 — фразы из главы 3.

## Термины

- **Источник** — то, что человек изучает как целое: книга, сериал, статья, песня.
- **Часть** — кусок содержимого источника со своим документом и, возможно, своим видео: глава EPUB, раздел статьи, серия, дописанный кусок. У источника с текстом хотя бы одна часть; у темы и Saved phrases частей нет, их карточки без `part_id`.
- **Карточка** (`StoredCandidate`) — одно **вхождение** слова в тексте с фразой вокруг него. Слово, встретившееся 5 раз, — 5 карточек. Пользователь видит слово и его «другие фразы», а не пять карточек.
- **Порция** — набор слов, взятых в работу одним действием, с параметрами взятия: откуда, сколько, в каком порядке. Карточка входит не более чем в одну порцию.
- **Показанная карточка слова** — у слова видна одна карточка: решённая, иначе входящая в порцию, иначе с лучшей оценкой фразы (оценка фрагмента), при равенстве — раньше по тексту.
- **Решение** — LEARN / KNOWN / SKIP, по слову.
- **Нетронутая карточка** — без решения, без результатов генерации и не в порции. Только такие приложение пересобирает само. Понятие внутреннее, в UI его нет.

## Почему карточка на вхождение

Сейчас на слово в источнике одна карточка с лучшей фразой среди первых десяти вхождений. Это баг: при порции из главы 3 слово из главы 3 пропадает или показывает фразу из другой главы; выбор смещён к началу текста. Карточка на вхождение убирает это без особых случаев: выборка — обычный `WHERE` по части и позиции, затем одна показанная карточка на слово.

Объём: строка на вхождение слова выше уровня; книга 168 тыс. слов — 12,8 тыс. вхождений. Генерация касается только показанных карточек. Индексы `(source_id, lemma)`, `(part_id, block)`.

## Как пользуется (UI)

### Экран источника

- Показывает **текущую порцию** (по умолчанию — последнюю). В шапке: «Порция 3 · Гл. 3 · по тексту · 37/100 решено».
- **Список порций** (выпадающий список в шапке): «Гл. 3 · 64/100», «Вся книга · 100/100», … — к старой порции можно вернуться.
- **«Все слова»** — последний пункт того же списка: все слова источника (показанная карточка на слово), сколько их («1 240 слов»). Здесь видно, что ещё осталось; отсюда можно взять отдельное слово в текущую порцию.
- Разделы Ready / Extra / Probably known — как сейчас, свёрнутые секции в списке (`candidate-sections.md`), не фильтр.
- **Сортировки как отдельного меню нет** (решено 14.10.2026): порядок — параметр порции, по нему слова и берутся, и показываются. «Все слова» — по порядку «самые полезные». Порядок по умолчанию в диалоге порции: песня и субтитры — по тексту, остальное — самые полезные.
- Правая панель — текст части, где стоит текущая карточка; переключатель частей над текстом, если частей ≥ 2. Карточки текущей порции подсвечены ярко, остальные слова — бледно. Клик по бледному слову: у слова есть карточка в порции — «выбрать эту фразу вместо текущей», нет — «взять слово в порцию». У порции «с этого места» видна метка начала, панель открывается на ней.

### Новая порция

Кнопка «Новая порция» (в шапке и пустом состоянии) открывает маленький диалог; у каждого поля значение по умолчанию:

1. **Откуда:** вся книга / часть (глава, серия; можно несколько подряд) / «с этого места» — место выбирается кликом в тексте правой панели или берётся конец предыдущей порции «по тексту».
2. **Сколько:** `cards_per_take` из настроек (100), можно поменять тут же.
3. **Порядок:** самые полезные / по тексту / ключевые слова.

Под полями — «Будет взято ~100 слов из 412 доступных». После нажатия: пересборка нетронутых карточек, взятие, экран переходит на новую порцию. Короткая строка в шапке: «Обновлено по текущим знаниям: 37 карточек».

Пустое состояние (у источника нет порций, например после «Добавить часть»): «Порций пока нет» и кнопка «Новая порция» с предзаполненным «Откуда».

### После загрузки и после «Добавить часть»

- Загрузка: первая порция берётся сама (вся книга, 100, порядок по умолчанию) — как при «Новая порция» с параметрами по умолчанию.
- «Добавить часть» (кнопка на экране источника и в меню строки источника): после добавления сразу открывается «Новая порция» с «Откуда» = новая часть. Сериал по серии в день: добавил серию → подтвердил порцию.

### Другая фраза для слова

На карточке — «Другие фразы (N)»: список вхождений слова с фразами (и клик по подсвеченному вхождению в правой панели — то же действие). Выбор: выбранная карточка встаёт в порцию вместо прежней; прежняя покидает порцию всегда, её генерация сохраняется, но не показывается.

### Обновить

Кнопка ↻ «Обновить» (на экране источника и в меню строки источника вместо Reprocess), одно действие:

- пересобирает слова, ещё не взятые в порции, по текущей логике и знаниям;
- галочка «Также незавершённые карточки порций» — пересобираются и взятые, но нерешённые; у карточки с новой фразой результаты AI сбрасываются. До подтверждения видно, сколько карточек изменится;
- подпись: «Новый промпт AI применяется через ✨ → Regenerate» — «Обновить» отвечает за отбор слов и фраз, не за AI.

### Генерация

Меню ✨ работает по текущей порции (счётчики и запуск). В «Все слова» генерация — с подтверждением, если карточек больше `cards_per_take`: «Сгенерировать 2 340 карточек?».

### Прогресс

- Шапка: решено в текущей порции (по Ready).
- Список источников: «ещё ~1 240 слов» + прогресс взятого.
- Статус источника «разобран» — см. открытые вопросы.

### Домен

- `SourcePart` (entity): `has_video`, `can_polish_phrases` переезжают сюда с `Source`.
- `Portion` (entity): параметры взятия + `label` («Гл. 3 · по тексту»).
- `PortionSpec` (value object): `parts: frozenset[int] | None`, `start: PartPosition | None`, `size: int`, `sort: CandidateSortOrder`.
- `shown_cards` (domain service): одна карточка на слово по правилу показанной карточки.
- `expected_section` (domain service): раздел, ожидаемый у готовой карточки — для порядка взятия.
- `StoredCandidate.is_untouched`.

## Поведение

### Загрузка

- `FormatReader` → `KindHandler` → `SourceWriter` создаёт источник и части:
  - EPUB — часть на главу (`infrastructure/epub/chapters.py`); вопрос `book.split` и источник на главу удаляются;
  - Markdown/HTML — часть на раздел верхнего уровня, если заголовки есть; иначе одна часть;
  - видео / SRT / YouTube / текст / песня — одна часть.
- Обработка: `RebuildCards`, затем `TakePortion` с параметрами по умолчанию.

### Пересборка — `RebuildCards(source_id, include_open)`

1. Анализ каждой части (`AnalyzeText` по текущему уровню, словарю, частотности): для **каждого** вхождения — фраза и её оценка.
2. Нетронутые карточки удаляются, на их место — карточки из анализа. Вхождения слов с решением не создаются.
3. `include_open`: карточки порций без решения сверяются с анализом по (лемма, POS, часть, позиция цели): фраза та же — без изменений; другая — новые фраза, позиция, слова, оценка, результаты AI по фразе (polish, meaning, TTS, media) сбрасываются; вхождения нет — карточка удаляется. Отказ при активных заданиях генерации.
4. Решённые карточки и карточки с генерацией вне `include_open` не трогаются никогда.

Замер 14.10.2026 (книга 168 тыс. слов, после исправления выбора фразы в пределах предложения): анализ всех вхождений 38 с, из них spaCy 30 с. Разбор spaCy кэшируется (`part_parses`), повторная пересборка ~8 с.

### Новая порция — `TakePortion(source_id, spec)`

1. `RebuildCards(include_open=False)`.
2. Карточки в `spec.parts` (и после `spec.start`, если задано), слова без решения и не в порции → `shown_cards` → порядок: по `expected_section`, затем `spec.sort` → первые `spec.size` получают новую порцию.
3. Результат: порция и число обновлённых при пересборке карточек (для строки «Обновлено…»).

`expected_section`: часть с Polish — PROBABLY_KNOWN для мусора и частых слов, иначе READY (сложность исходной фразы снимает Polish); часть без Polish (видео) — раздел исходной фразы. Polish наперёд и Polish всего источника отвергнуты (14.10.2026).

«С этого места» по умолчанию для порядка «по тексту» — конец предыдущей такой порции в той же части.

`PreviewPortion(source_id, spec)` — «будет взято ~N из M доступных» без пересборки.

### Другая фраза — `ChooseOccurrence(candidate_id)`

Выбранная карточка получает порцию прежней показанной карточки слова; прежняя порцию теряет всегда.

### Взять слово в порцию — `TakeWord(candidate_id, portion_id)`

Из «Все слова»: показанная карточка слова встаёт в порцию.

### Обновление — `UpdateSource(source_id, include_open)` + `PreviewUpdate`

`RebuildCards(include_open)`; `PreviewUpdate` считает, сколько незавершённых карточек получат новую фразу. `ReprocessSource`, `GetReprocessStats`, `ReprocessModal`, кэш обогащения удаляются.

### Дописать часть — `AddPart(source_id, input, title?)`

Часть в конец, название по умолчанию «Part N»; затем `RebuildCards(include_open=False)`. Порция не берётся сама — фронт открывает «Новая порция» с этой частью.

### Решение

`DecideCard(candidate_id, status)`: статус на эту карточку; нетронутые карточки того же слова в источнике удаляются; тронутые остаются скрытыми. Экспорт по статусу — слово уходит в Anki один раз. Отдельной сущности «слово» нет.

### Чтение и генерация

- `GetSource(source_id, view)`, где `view` — порция или «все слова»: карточки порции (или показанные карточки всех слов) → разделы → порядок порции (для «все слова» — самые полезные).
- `GetSourceDocument(part_id)`: документ части, подсветка — показанные карточки части.
- `GetGenerationStatus` / `RunGeneration(..., view)` — по карточкам вида.

### Генерация и видео

- `GenerationTarget.applies_to` и `blocker` принимают часть карточки.
- Медиа и скачивание видео — по части карточки.

## API (кратко)

- `GET /sources/{id}?portion=|all` — деталь + `parts`, `portions: [{id, number, label, decided, total}]`, `remaining`.
- `POST /sources/{id}/portions` `{spec}`; `POST /sources/{id}/portions/preview` `{spec}`.
- `POST /candidates/{id}/choose`; `POST /candidates/{id}/take` `{portion_id}`.
- `POST /sources/{id}/update` `{include_open}`; `POST /sources/{id}/update/preview`.
- `POST /sources/{id}/parts`.
- Генерация — `?portion=|all`. Удаляются `/reprocess`, `/reprocess-stats`.

## Миграция 0049

- `source_parts`: часть на источник (`position=0`, `title` — название источника, формат и видео — из `sources`).
- `part_documents` из `source_documents`.
- `portions`: у каждого источника с карточками — порция №1 «Всё» (`part_ids` NULL, `size` = число карточек, `sort_order` relevance); все существующие карточки — в ней; `fragment_score` — NULL.
- Удаляются столбцы `sources.format/source_url/video_path/audio_track_index`, таблицы `source_documents`, `enrichment_cache`.
- Перед созданием проверить номер на всех ветках.

## Открытые вопросы

1. **Статус «разобран».** Раньше решено: разобраны все Ready во всём источнике, включая невзятые. Ревью предлагает: разобрано всё взятое (иначе статус почти недостижим на книге). Решить.
2. **Генерация в «Все слова».** Раньше решено: можно, генерирует всё. Сейчас — с подтверждением. Нужна ли она там вообще?
3. **«С этого места» по клику в тексте** — подходит ли как замена страниц для длинной статьи без заголовков?

## Вне задачи

- Когда Learn считается знакомым (через Anki) — отдельная фича.
- Универсальная кнопка генерации — отдельная задача.
- Быстрый рендер огромного текста в правой панели — отдельно.
