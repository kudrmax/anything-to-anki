# Части источника, порции и обновление без потерь

Продуктовые решения согласованы с Максом 14.10.2026, история обсуждения — в документе «Большие источники — проблема». После продуктового ревью спеки фильтры «Где» / «В работе» заменены **порциями** (решение Макса 14.10.2026).

## Цель

Большой источник (книга, сериал, огромная статья) не генерируется целиком и не замораживается на момент загрузки.

- Человек явно берёт **порцию** слов: откуда, сколько и в каком порядке — видно в момент взятия, ничего не зависит от скрытого состояния экрана.
- Карточки, во что человек ещё ничего не вложил, всегда можно пересобрать по текущей логике и знаниям, не трогая остальное.
- Фраза для слова берётся из выбранного куска: готовишься к главе 3 — фразы из главы 3.

## Термины

- **Источник** — то, что человек изучает как целое: книга, сериал, статья, песня.
- **Часть** — кусок содержимого источника со своим документом и, возможно, своим видео: глава EPUB, раздел статьи, серия, дописанный кусок. У источника с текстом хотя бы одна часть; у темы и Saved phrases частей нет.
- **Слово** (карточка, `StoredCandidate`, таблица `candidates` — как сейчас, одно на лемму+POS в источнике): решение и **фраза, на которой оно принято** (`decided_phrase_id` — она уходит в Anki), CEFR, частотность, usage, произношение, картинка. Экспорт, Anki-синхронизация, жалобы — по слову, как сейчас.
- **Фраза** (`Phrase`, таблица `phrases`) — вхождение слова в тексте: часть, место цели (`target_start`, `target_end` в координатах документа части — стабильный ключ вхождения), текст фразы, её слова, оценка фрагмента, и всё, что сгенерировано **для фразы**: Polish, определение (смысл зависит от контекста), озвучка фразы, видеоклип, cloze, ручная граница. Много фраз на слово.
- **Порция** — набор **фраз**, взятых в работу одним действием, с параметрами взятия (откуда, сколько, порядок). Одно слово может быть в нескольких порциях, каждый раз со своей фразой (порция «вся книга» — фраза из гл. 1, порция «гл. 3» — фраза из гл. 3). Модель данных не ограничивает и число фраз одного слова внутри порции.
- **Отбор фраз** — отдельный шаг после анализа, одна заменяемая функция (`select_phrases`): сейчас правило «одна лучшая фраза на слово в порции», остальные пользователю не показываются вообще. Другое правило в будущем меняет только этот шаг.
- **Сменить фразу** — в порции фраза слова заменяется другой фразой того же слова. Старая фраза со своими результатами остаётся в базе; вернулся к ней — всё на месте.
- **Решение** — LEARN / KNOWN / SKIP, на слове: решённое в одной порции слово в других порциях показывается решённым; новая порция решённые слова не берёт.
- **Тронутая фраза** — входит в порцию, или фраза решения, или с любым результатом генерации, или с ручной правкой (граница, ручное добавление, пример как фраза), или с поставленной задачей генерации. Нетронутые фразы пересобираются свободно. Одно доменное определение, SQL-фильтр строится из него и проверяется тем же тестом.

## Почему так

Сейчас на слово одна карточка с одной фразой из первых десяти вхождений: при порции из главы 3 слово показывает фразу из другой главы. Разделение «слово / фразы» решает это без дублирования данных слова и без потерь: порция из главы 3 берёт фразы главы 3; фразы и результаты других порций не трогаются. Решено с Максом 14.10.2026 после технического ревью (вариант «карточка на вхождение» отвергнут: дублирование данных слова, удаление соседей при решении, смена id карточек).

Объём: книга 168 тыс. слов — ~4 тыс. слов и ~12,8 тыс. фраз; фразы лёгкие (без данных слова).

## Как пользуется (UI)

### Экран источника

- Показывает **текущую порцию** (по умолчанию — последнюю). В шапке — выпадающий список порций: «Порция 3 · Гл. 3 · по тексту · 37/58 Ready», «Порция 2 · Вся книга · 100/100», …, последним пунктом «+ Новая порция…». Рядом счётчик «ещё ~1 240 слов».
- Вида «Все слова» нет (решено 14.10.2026): невзятые слова видны бледными в правой панели и берутся кликом; остаток — счётчиком.
- Разделы Ready / Extra / Probably known — как сейчас, свёрнутые секции в списке (`candidate-sections.md`).
- **Сортировки как отдельного меню нет**: порядок — параметр порции, по нему фразы и берутся, и показываются. По умолчанию: песня и субтитры — по тексту, остальное — самые полезные.
- Правая панель — текст части, где стоит текущая карточка; переключатель частей, если частей ≥ 2. Фразы текущей порции подсвечены ярко, остальные вхождения слов — бледно. Клик по бледному: слово уже в порции — «Взять эту фразу вместо текущей», нет — «Добавить в порцию». Действие «Новая порция отсюда» — в меню выделения текста. У порции «с места» видна метка начала, панель открывается на ней.
- Если у источника одна порция и больше брать нечего (песня) — список порций и счётчик скрыты, экран как сейчас.

### Новая порция

Диалог, у каждого поля значение по умолчанию **из прошлой порции**:

1. **Откуда:** вся книга / часть (можно несколько подряд) / с места (из «Новая порция отсюда» или продолжение прошлой порции «по тексту»).
2. **Сколько:** из прошлой порции, иначе `cards_per_take` (100).
3. **Порядок:** самые полезные / по тексту / ключевые слова.

Под полями — «Будет взято ~100 из 412». «По тексту» берёт **сплошной кусок** текста (без перестановки по разделам); в подписи порции видно, где кусок кончается. После нажатия: пересборка нетронутых фраз, взятие, переход на новую порцию; строка «Обновлено по текущим знаниям: 37 фраз».

Взятие ничего не генерирует: генерацию запускает человек через меню ✨ (по текущей порции).

### После загрузки и после «Добавить часть»

- Загрузка: первая порция берётся сама (вся книга, 100, порядок по умолчанию).
- «Добавить часть» (на экране источника и в меню строки источника): после добавления сразу открывается «Новая порция» с «Откуда» = новая часть.

### Другие фразы

На карточке — «Другие фразы (N)»: вхождения слова с фразами; клик по вхождению в правой панели — то же. Выбор заменяет фразу слова в этой порции; прежняя фраза со своими результатами остаётся в базе.

### Обновить

Кнопка ↻ (на экране источника и в меню строки вместо Reprocess), одно действие: пересобирает нетронутые фразы по текущей логике и знаниям. Галочка «Также незавершённые фразы порций» — пересобираются и фразы порций без решения; у фразы с новым текстом результаты AI сбрасываются; до подтверждения видно, сколько изменится. Подпись: «Новый промпт AI применяется через ✨ → Regenerate».

### Прогресс

- Шапка: решено Ready в текущей порции («37/58 Ready»).
- Список источников: прогресс по порциям + «ещё ~N слов». Источник в стадии «разобран», когда Ready всех порций решены (пересмотреть на опыте).

### Домен

- `SourcePart` (entity): `has_video`, `can_polish_phrases` — единственное место правила «можно ли Polish» (его спрашивают и `PolishTarget`, и `expected_section`).
- `Phrase` (entity), `StoredCandidate` (слово) с `decided_phrase_id`.
- `select_phrases(phrases_in_scope) -> list[Phrase]` (domain service): отбор фраз для порции — сейчас лучшая на слово.
- `Portion` (entity), `PortionSpec` (VO): части, начало, размер, порядок.
- `plan_rebuild(existing, built) -> RebuildPlan` (domain service): чистый расчёт пересборки — какие фразы создать, удалить, какие слова лишаются всех фраз; превью = счётчики плана, выполнение = применение плана.
- `best_phrase(phrases, scope)` (domain service): лучшая фраза слова в области порции (минимальная оценка, при равенстве раньше по тексту).
- `expected_section` (domain service): раздел, ожидаемый у готовой карточки — для порядка взятия.
- `is_touched(phrase)` (domain spec) — одно определение тронутой фразы.

## Поведение

### Загрузка

- `FormatReader` → `KindHandler` → `SourceWriter` создаёт источник и части:
  - EPUB — часть на главу (`infrastructure/epub/chapters.py`); вопрос `book.split` и источник на главу удаляются;
  - Markdown/HTML — часть на раздел верхнего уровня, если заголовки есть; иначе одна часть;
  - видео / SRT / YouTube / текст / песня — одна часть.
- Обработка: `RebuildCards`, затем `TakePortion` с параметрами по умолчанию.

### Пересборка — `RebuildCards(source_id, include_open)`

1. Анализ каждой части (`AnalyzeText` по текущему уровню, словарю, частотности): для **каждого** вхождения — фраза и её оценка.
2. Нетронутые карточки удаляются, на их место — карточки из анализа. Вхождения слов с решением не создаются.
3. `include_open`: карточки порций без решения сверяются с анализом по (лемма, POS, часть, позиция цели): фраза та же — без изменений; другая — новые фраза, позиция, слова, оценка, результаты AI по фразе (polish, meaning, TTS, media) сбрасываются; вхождения нет — карточка удаляется. Отказ при активных заданиях генерации.
4. Решённые карточки и карточки с генерацией вне `include_open` не трогаются никогда.

Замер 14.10.2026 (книга 168 тыс. слов, после исправления выбора фразы в пределах предложения): анализ всех вхождений 38 с, из них spaCy 30 с. Разбор spaCy кэшируется (`part_parses`), повторная пересборка ~8 с.

### Новая порция — `TakePortion(source_id, spec)`

1. `RebuildCards(include_open=False)`.
2. Карточки в `spec.parts` (и после `spec.start`, если задано), слова без решения и не в порции → `shown_cards` → порядок: по `expected_section`, затем `spec.sort` → первые `spec.size` получают новую порцию.
3. Результат: порция и число обновлённых при пересборке карточек (для строки «Обновлено…»).

`expected_section`: часть с Polish — PROBABLY_KNOWN для мусора и частых слов, иначе READY (сложность исходной фразы снимает Polish); часть без Polish (видео) — раздел исходной фразы. Polish наперёд и Polish всего источника отвергнуты (14.10.2026).

«С этого места» по умолчанию для порядка «по тексту» — конец предыдущей такой порции в той же части.

`PreviewPortion(source_id, spec)` — «будет взято ~N из M доступных» без пересборки.

### Другая фраза — `ChooseOccurrence(candidate_id)`

Выбранная карточка получает порцию прежней показанной карточки слова; прежняя порцию теряет всегда.

### Взять слово в порцию — `TakeWord(candidate_id, portion_id)`

Из «Все слова»: показанная карточка слова встаёт в порцию.

### Обновление — `UpdateSource(source_id, include_open)` + `PreviewUpdate`

`RebuildCards(include_open)`; `PreviewUpdate` считает, сколько незавершённых карточек получат новую фразу. `ReprocessSource`, `GetReprocessStats`, `ReprocessModal`, кэш обогащения удаляются.

### Дописать часть — `AddPart(source_id, input, title?)`

Часть в конец, название по умолчанию «Part N»; затем `RebuildCards(include_open=False)`. Порция не берётся сама — фронт открывает «Новая порция» с этой частью.

### Решение

`DecideCard(candidate_id, status)`: статус на эту карточку; нетронутые карточки того же слова в источнике удаляются; тронутые остаются скрытыми. Экспорт по статусу — слово уходит в Anki один раз. Отдельной сущности «слово» нет.

### Чтение и генерация

- `GetSource(source_id, view)`, где `view` — порция или «все слова»: карточки порции (или показанные карточки всех слов) → разделы → порядок порции (для «все слова» — самые полезные).
- `GetSourceDocument(part_id)`: документ части, подсветка — показанные карточки части.
- `GetGenerationStatus` / `RunGeneration(..., view)` — по карточкам вида.

### Генерация и видео

- `GenerationTarget.applies_to` и `blocker` принимают часть карточки.
- Медиа и скачивание видео — по части карточки.

## API (кратко)

- `GET /sources/{id}?portion=|all` — деталь + `parts`, `portions: [{id, number, label, decided, total}]`, `remaining`.
- `POST /sources/{id}/portions` `{spec}`; `POST /sources/{id}/portions/preview` `{spec}`.
- `POST /candidates/{id}/choose`; `POST /candidates/{id}/take` `{portion_id}`.
- `POST /sources/{id}/update` `{include_open}`; `POST /sources/{id}/update/preview`.
- `POST /sources/{id}/parts`.
- Генерация — `?portion=|all`. Удаляются `/reprocess`, `/reprocess-stats`.

## Миграция 0049

- `source_parts`: часть на источник (`position=0`, `title` — название источника, формат и видео — из `sources`).
- `part_documents` из `source_documents`.
- `portions`: у каждого источника с карточками — порция №1 «Всё» (`part_ids` NULL, `size` = число карточек, `sort_order` relevance); все существующие карточки — в ней; `fragment_score` — NULL.
- Удаляются столбцы `sources.format/source_url/video_path/audio_track_index`, таблицы `source_documents`, `enrichment_cache`.
- Перед созданием проверить номер на всех ветках.

## Решения без продуктовой проверки (пересмотреть на опыте)

1. Статус «разобран» — по порциям, не по всему источнику.
2. Генерация в «Все слова» есть, с подтверждением при числе карточек больше `cards_per_take` (ранее решено, что генерировать там можно).
3. «С этого места» — клик в тексте правой панели или конец предыдущей порции «по тексту»; страниц нет.

## Вне задачи

- Когда Learn считается знакомым (через Anki) — отдельная фича.
- Универсальная кнопка генерации — отдельная задача.
- Быстрый рендер огромного текста в правой панели — отдельно.
