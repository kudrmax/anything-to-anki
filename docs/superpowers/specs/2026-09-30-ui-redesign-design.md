# Редизайн web UI

Дата: 2026-09-30. Эталон: [docs/design/ui-mockups.html](../../design/ui-mockups.html) — шесть экранов, открывается в браузере.

## Цель

Приложение нужно, чтобы долго читать фразы и по каждой быстро решать: учу, знаю, пропускаю. Нынешний интерфейс — смесь «стекла» в духе iOS 26 и трёх старых тем — с этим спорит: много рамок, плашек и равнозначных карточек. Новый интерфейс ставит текст на первое место.

Критерий успеха: каждый экран приложения совпадает с макетом, старые темы и «стеклянные» стили удалены, функциональность не потеряна.

## Границы

- Меняется только `frontends/web`. Backend, API и типы ответов не трогаем.
- Вся логика остаётся в backend. Хоткеи, раскрытие строки и тема — локальное состояние UI.
- Состав настроек и действий на экранах не меняется; меняется подача.

## Визуальная система

Одна система вместо тем Cosmic / Liquid Glass / Book. Значения — CSS-переменные в `index.css`, как в макете.

| Токен | Тёмная | Назначение |
|---|---|---|
| `--bg` | `#100f0e` | фон страницы, поверх — тёплое свечение в двух углах |
| `--card` | `#181716` | поверхность: раскрытая строка |
| `--soft` | `#222120` | фон контролов, подсветка строки под курсором |
| `--line` | `#2c2b2a` | рамка поверхности, разделители |
| `--tx` / `--tx2` / `--tx3` | `#e9e8e7` / `#bbbab9` / `#8c8c8a` | текст: основной, второстепенный, подписи |
| `--ac` | `#eda57c` | акцент: изучаемое слово, активные состояния |
| `--fill` | градиент `#e08e5e → #eaa97f` | основная кнопка |
| `--ok` / `--warn` / `--err` | `#a9cf9a` / `#e6bd74` / `#f09a8e` | статусы |

Светлая тема — набор значений из макета (`[data-theme="light"]`). Переключатель в Settings: Light / Dark / System, хранится в `preferences.ts`.

Правила:

- Шрифт — Geist для всего, Geist Mono только для транскрипции и клавиш. Подключается локально через fontsource, как сейчас Inter.
- Два радиуса: 16px у строк и поверхностей, 12px у всех контролов.
- Контролы (кнопка, поле, чип, сегментный переключатель, иконка-кнопка) — высота 36px, без рамок, фон `--soft`.
- Рамка 1px `--line` есть только у поверхности и разделителей.
- Акцентный цвет — только на изучаемом слове и основном действии.
- Иконки — `lucide-react`, уже используется.

## Каркас

- Слева узкая колонка навигации: Sources, Export (со счётчиком), Queue, внизу Settings; метка окружения под логотипом.
- Каждый экран — одна сетка: колонка контента 720px и правая колонка 310px. Заголовок, первая строка и правая колонка стоят на одних координатах на всех экранах.
- Заголовок экрана: название слева, действия справа. На вложенных экранах (Review, Calibrate) перед названием стрелка «назад».
- Контент — общий компонент «строка»: точка статуса, заголовок, подпись, справа статус и действие.

## Экраны

**Sources.** Список источников строками. Справа — форма Add source (Text / URL / File, тип источника) и прогресс. Фильтр по коллекциям — в заголовке. Reprocess и Delete появляются при наведении.

**Review.** Список фраз; одна раскрыта, остальные — строки.
- Раскрытая: фраза 25px, изучаемое слово акцентом; строка с типом, частотностью, транскрипцией и аудио US / UK / TTS; определение, пояснение контекста, перевод и синонимы, примеры; превью медиа; Learn / Know / Skip; действия над кандидатом (значение, медиа, TTS, правка фрагмента).
- После решения строка сворачивается с отметкой, раскрывается следующая нерешённая. Клик по строке раскрывает её.
- Хоткеи (новое): `↑` `↓` — соседняя фраза, `1` `2` `3` — Learn / Know / Skip, `Space` — аудио. Не срабатывают, когда фокус в поле ввода.
- Справа — текст источника: кандидаты подчёркнуты, текущий выделен акцентом. Выделение текста показывает «+ Add as target» (существующий `TextSelectionPopover`).
- В заголовке: прогресс, сортировка Relevance / Text order, меню Generate (Meanings / Media / Pronunciation), Export.

**Export** (общий и по источнику). Карточки строками, сгруппированы по источнику; справа — колода, тип заметки, сколько готово. Карточка без значения помечена и предлагает сгенерировать.

**Queue.** Задачи строками; справа сводка по типам. В заголовке: фильтр по источнику, Retry failed, Cancel queued.

**Settings.** Секции строками с разделителями; оглавление справа. Состав настроек прежний, кнопка Save settings остаётся. Appearance: Light / Dark / System вместо трёх тем.

**Calibrate.** Слова-плашки, Next и Finish; справа — раунд и число проверенных слов.

Не нарисованы в макете и делаются в той же системе: окно Reprocess, переименование источника, пустые состояния, ошибки загрузки.

## Что удаляется

`AmbientBlobs`, `NavPill`, `PageToolbar` и слоты тулбара, `ThemeProvider` с тремя темами, `design-tokens.ts`, стили `.glass-*` и блоки `[data-theme="liquid-glass"]` / `book` в `index.css`, неиспользуемый `CandidateCard` (если подтвердится, что остался только `CandidateCardV2`), `App.css`.

## Порядок работ

1. Токены, шрифты, каркас (навигация, сетка, заголовок) и общие компоненты: строка, кнопка, поле, чип, сегментный переключатель, точка статуса.
2. Экраны по одному: Sources → Review → Export → Queue → Settings → Calibrate. После каждого приложение собирается и работает.
3. Удаление старых стилей и компонентов.
4. Сверка с макетом.

## Проверка

- `npm run build` и `npm run lint` в `frontends/web`, `make lint` и `make typecheck` — без ошибок. Автотестов у фронтенда нет; backend-тесты (`make test`) должны остаться зелёными.
- Сверка с макетом на dev-экземпляре (`make up`): для каждого из шести экранов — скриншот приложения рядом со скриншотом макета при ширине 1440px, плюс измерение координат заголовка, первой строки и правой колонки, высот контролов и радиусов. Расхождения исправляются до совпадения.
- Ручной прогон: добавить источник, пройти Review мышью и клавишами, сгенерировать значение, экспортировать в Anki, сохранить настройки, переключить тему.
