# AnythingToAnki

Учить английский на том, что ты и так смотришь, слушаешь и читаешь. Даёшь источник: фильм, видео, песню, статью. Приложение находит в нём новые для тебя слова, фразовые глаголы и коллокации и делает по каждому готовую карточку: фраза из этого же источника, где всё остальное тебе уже знакомо. Карточки идут списком, сверху самые полезные для изучения. Ты размечаешь их: «учу» или «знаю». Карточки «учу» уходят в Anki, а слова «знаю» больше не предлагаются.

Работает локально на macOS, на сервер не поднимается.

## Что нужно

- macOS
- [Claude Code](https://claude.com/claude-code), в котором выполнен вход: AI-генерация идёт через него, API-ключ не нужен
- Anki с плагином AnkiConnect
- Словари из [anything-to-anki-dicts](https://github.com/kudrmax/anything-to-anki-dicts), формат — в [dictionaries/README.md](dictionaries/README.md)

## Запуск

```bash
make setup
cp .env.example .env    # указать DICTIONARIES_DIR
make up
```

Остановить — `make down`, логи — `make logs`, все команды — `make help`.
